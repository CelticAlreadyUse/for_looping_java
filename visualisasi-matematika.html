Dua akar, satu parabola.

Tabel seperti perulangan Java

Mulai dari akar terkecil, tambah x sebesar 0,25. Akar terbesar ikut masuk jika tercapai oleh langkah tersebut. Maksimal 400 baris ditampilkan.

y = ax² + bx + c
D = b² − 4ac
x₁,₂ = (−b ± √D) / (2a)

Cara membaca grafik

Akar adalah nilai x saat y = 0: titik perpotongan kurva dengan sumbu x. Titik lingkaran menandai akar real.

a > 0: parabola terbuka ke atas.
a < 0: parabola terbuka ke bawah.

Keputusan dalam kode

a == 0 → bukan persamaan kuadrat.
D > 0 → dua akar real berbeda.
D == 0 → akar real kembar.
D < 0 → tidak ada akar real.

Sesuai latihan, tabel y hanya dihitung saat D > 0. Grafik tetap ditampilkan untuk membantu melihat kasus lainnya.

Setiap suku punya dua pendahulu.

Jejak perubahan variabel

F₁ = 1, F₂ = 1
Fₙ = Fₙ₋₁ + Fₙ₋₂

Mengikuti cara kode kamu

Mulai dengan firstFibonacci = 1 dan secondFibonacci = 0.

  1. Jumlahkan kedua nilai untuk mendapat suku baru.
  2. Simpan suku baru ke secondFibonacci.
  3. Kurangi suku baru dengan nilai firstFibonacci lama. Hasilnya adalah nilai secondFibonacci lama.
  4. Cetak suku baru, kemudian ulangi.

Kolom “awal” dibaca sebelum pembaruan, sedangkan “akhir” dibaca setelah pembaruan. Tinggi batang menunjukkan besar nilai suku, bukan nomor sukunya.

Visual dibatasi sampai 20 suku agar terbaca. Pada kode Java dengan tipe int, hasil mulai melampaui kapasitas pada suku ke-47.

Satu data, tiga operasi.

Gunakan titik untuk desimal, misalnya 2.5. Maksimal 20 data; setiap nilai antara −100 dan 100.

Jumlah kuadrat = Σx²
Jumlah akar = Σ√x
Jumlah kebalikan = Σ(1/x), x ≠ 0

Perhatikan pengecualiannya

Kuadrat: hasil x × x selalu tidak negatif untuk bilangan real.

Akar: √x hanya real untuk x ≥ 0. Jika satu saja data negatif, jumlah akar seluruh data tidak terdefinisi dalam bilangan real.

Kebalikan: data nol dilewati karena 1/0 tidak terdefinisi. Data negatif tetap ikut dijumlahkan.

Tiga batang menampilkan hasil total pada skala yang sama. Tabel memisahkan kontribusi masing-masing data. Simbol Σ berarti “jumlahkan”.

Kode: JumlahAkarKuadrat.java

Komponen sama, susunan berbeda.

Pisahkan dengan spasi atau koma; gunakan titik untuk desimal. Masukkan 1–6 resistor dengan nilai lebih dari 0 sampai 1.000.000 Ω.

Seri: R = R₁ + R₂ + … + Rₙ
Paralel: 1/R = 1/R₁ + … + 1/Rₙ

Mengapa hasilnya berbeda?

Seri: arus melewati setiap resistor secara berurutan. Total tahanan adalah penjumlahan semua resistor.

Paralel: arus mempunyai beberapa jalur. Untuk lebih dari satu resistor positif, tahanan total lebih kecil daripada resistor terkecil.

Untuk 10 Ω dan 20 Ω:
Seri = 10 + 20 = 30 Ω.
Paralel = 1 / (1/10 + 1/20) ≈ 6,667 Ω.

Visual ini memakai tahanan positif. Kode Java mengikuti pseudocode dan belum memvalidasi setiap nilai tahanan.

Kode: Resistor.java
